# دفتر | Daftar — موجز المنتج

دليل مختصر يغني عن ذاكرة المحادثة. الاسم الإنجليزي للمنتج: **Daftar**. في الواجهة العربية: **دفتر**.

> مستودع مستقل عن SiteFlow. لا تخلط المنتجين ولا تعدّل SiteFlow من عمل Daftar.

## ماذا يحل؟

مقاول تشطيب يحتاج دفتر فلوس بسيط لكل مشروع: كام دخل من العميل، كام اتصرف في الموقع، كام باقي، مع صور وإثباتات وكشف حساب يُطبع أو يُحفظ PDF، وعرض للعميل للقراءة فقط.

الإلهام في البساطة: تطبيق مُعَمِّر (Muamer) — شاشة واحدة لمهمة واحدة، عربي عامي مصري، RTL.

## النواة (داخل النطاق)

| القدرة | ملاحظة |
|--------|--------|
| دفعات العميل | تسجيل ما استُلم للمشروع |
| مصروفات الموقع | مع مرفقات اختيارية (صور / إثبات) |
| فئات وبنود | تنظيم الصرف |
| ملخص المال | وارد / منصرف / متبقي |
| معرض الصور | أدلة بصرية من الموقع |
| بوابة العميل | قراءة فقط |
| كشف حساب | طباعة / PDF |

## للمساعدين (Agents)

1. اقرأ `.cursor/rules/daftar-product.mdc` (alwaysApply).
2. المصدر المعتمد للكود: مستودع Daftar المستقل، وليس مجلدًا داخل SiteFlow.
3. حافظ على بساطة Muamer: مهمة واحدة لكل شاشة، عربي عامي واضح.
4. إن وُجدت تفضيلات المستخدم: الرد على رامي بالعربية مع الإبقاء على `Daftar` وأسماء الملفات والروابط كما هي.
